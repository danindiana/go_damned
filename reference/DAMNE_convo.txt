## The paper in one paragraph

Spiking neural nets are sparse in time (low average firing rate), so time-driven simulators like GENESIS/NEURON waste effort scrolling every neuron every Δt. Event-driven simulation fixes that but is normally sequential. DAMNED makes EDS parallel on two axes at once: **coarse grain**, the topology is statically mapped across P processors talking over MPI; **fine grain**, each processor runs one thread per currently-computing neuron. The interesting contribution is what's *absent* — no synchronization barrier and no farmer/controller processor. Ordering is enforced locally, from event causality plus clock arrays that piggyback on the spike packets processors were sending anyway.

## The hard problem it solves

A spiking neuron forecasts its next firing time from the inputs it has integrated so far. But an inhibitory spike arriving later, with a *shorter* delay, can land at the soma *earlier* and cancel that forecast (diagram 04). So an outgoing spike sitting in a queue is provisional. DAMNED handles this with:

- a `crt` certification flag, set true once `st_j ≤ st_i + d_min_j` — i.e. no future input can possibly land before the forecast fires;
- two signed local variables, `et_p` (emission time) and `pt_p` (processing time), whose *sign* encodes "my queue is empty";
- authorization predicates (diagrams 05, 06) that release a spike only when neither local threads nor any remote processor could still invalidate it.

Deadlock is the price of having no barrier, and it's paid two ways: a per-processor *local deadlock detection* rule inside the CPC (`et_p < st_i` and every remote `et_m` is past or idle → fall back to comparing against the top of the CP queue), and a rarely-fired **time-out on Pr0** that bumps the global time `T` when the network goes so quiet that no output spike arrives.

## 1. The safety claim — and a counterexample

The paper's safety argument is a chain of dependencies, and the whole chain rests on one unstated lemma.

**What must be true for emission of `[N_i, st_i]` to be safe:** no spike anywhere in the system, not yet delivered to `N_i`, has an impact time `≤ st_i`. Impact time is `st_k + d_ki ≥ st_k + d_min_i`. So the requirement reduces to: *no unprocessed or in-flight spike has a stamp below `st_i − d_min_i`.* Call this **No-Straggler(st_i)**.

Now walk the four authorization branches:

- `st_i = et_p` → safe by induction on the previous emission.
- `crt = true` → certification set when `st_j ≤ (processed st_i) + d_min_j`. This says "every input I have *processed* lands too late to cancel." It says nothing about inputs not yet processed. **Requires No-Straggler.**
- `st_i ≤ pt_p` → "local processing has advanced past `st_i`." Same gap: the CM queue is sorted, but a *later-arriving* message can be inserted at the top with a smaller stamp. **Requires No-Straggler.**
- `nbth_p = 0 ∧ pt_p < 0 ∧ ∀m≠p [st_i ≤ et_m ∨ et_m ≤ 0]` → this is the branch that is supposed to *establish* No-Straggler.

So everything reduces to that last conjunct. And it does not hold.

**The bug is the sign trick.** `et_m ≤ 0` encodes "Pr_m's CP queue is empty right now." It is treated as vacuously satisfying the guard — as if idleness implied temporal advancement. It does not. `|et_m|` is Pr_m's *last emission*, not a lower bound on its *next* one, and an idle processor may hold a low-stamped, unprocessed CM event. The clock array carries `et` only; it never carries `pt`, and it never carries the stamp at the top of anyone's CM queue.

Concretely, with all delays `= 1` (so lookahead is strictly positive — the counterexample doesn't depend on zero delays):

| step | Pr1 | Pr2 |
|---|---|---|
| — | `et_1 = 3`, CM queue holds excitatory event `st=8` for `N_x` | `et_2 = −3` (CP queue empty), CM queue holds unprocessed event `st=4` for `N_b` |
| 1 | CPC: authorize `st=8`? `nbth=0`; `∀m [8 ≤ et_m ∨ et_m ≤ 0]` — Pr2 passes via `et_2 = −3`; Pr0 passes since `T = 9`. **Authorized.** `pt_1 ← 8` | idle in its loop |
| 2 | `N_x` crosses θ, forecasts spike at `st = 8`. CP event queued, `crt = false` | — |
| 3 | CMC: `st_i = 8 ≤ pt_1 = 8` → **emission authorized.** Spike leaves. | — |
| 4 | — | now computes `st=4`; `N_b` fires at `st = 5`; inhibitory, `d = 1`, targets `N_x` |
| 5 | receives inhibition impacting `N_x` at `t = 6 < 8` | — |

`N_x`'s spike at 8 should never have existed — this is precisely the Figure 1 cancellation scenario the paper is built to prevent — but it was committed at step 3. Exactness is violated.

Now the important part: **suppose I'm misreading the terse pseudocode**, and `et_m ≤ 0` is meant as shorthand for "idle *and* `st_i ≤ |et_m|`." Then the guard is genuinely conservative and the counterexample dies. But then a ring of mutually-idle processors, each waiting on the others' bounds, deadlocks — and the only escape is Pr0's time-out, which executes `et_p(0) ← T−1` for every `p`: it *fabricates* clock values it has not received. A processor genuinely sitting at `st = 4` is now advertised as being at `T−1 = 8`. The same violation reappears, one layer down.

**Both readings converge on the same conclusion**, which is what makes the criticism robust to my uncertainty about the pseudocode: the time-out is not a patch bolted onto a sound algorithm. It *is* the unsoundness, and simultaneously it is the only thing guaranteeing progress.

## 2. Liveness, and when the time-out actually fires

Pr0 advances global time with:

```
if (∃j ≥ 1) |et_j(q)| = T  then  T ← T+1 ; et_0 ← T
```

Two observations the paper doesn't make.

**The equality test is fragile.** Stamps come from spike forecasts — arbitrary integers. A processor can leap from `et = 7` to `et = 9`, and `|et_j| = 8` never holds. `T` then stalls until the time-out fires. This should almost certainly be `≥`.

**The time-out is not rare — and it is least rare exactly where DAMNED claims its advantage.** `T` advances only when an *output* neuron fires at exactly the current `T`. But the paper's entire motivation for event-driven simulation is that SNNs have "low average activity" and sparse, irregular firing. A sparsely-coding output layer is silent for long stretches by construction. In that regime, `T` is driven almost entirely by the time-out, not by spikes. The sparsity that justifies EDS is the same sparsity that starves Pr0's clock. That's an internal tension, and it's testable: instrument the time-out counter and sweep output-layer firing rate.

And the time-out has a cost the paper acknowledges only obliquely — *"provided that the time-out is sufficiently long."* Sufficiently long relative to what? MPI latency and processor speed. A simulator that claims exact firing times has just made its results a function of wall-clock and interconnect. Run the same network on a faster cluster, get different spikes. That is a reproducibility failure, not a performance note.

## 3. DAMNED against CMB and against the safe window

Here is the deflationary reading, and I think it's the correct one.

**DAMNED is Chandy–Misra–Bryant with the null messages centralized and renamed.** Pr0 broadcasts `Clk(0)` to every processor on every increment of `T`, and — the paper's own words — is "the only one that can send messages reduced to the clock." A message carrying nothing but a clock, sent to unblock receivers, *is* a null message. DAMNED has not eliminated them; it has routed all of them through one process, which also holds `T`, also broadcasts to everyone, and also breaks deadlocks. The claim "we avoid the implementation of a unique controller or farmer processor" does not survive contact with the `∀m` quantifier in the computation guard — which ranges over `m = 0`, gating *every* local computation on `st_i ≤ et_0 = T`.

The correspondence:

| CMB concept | DAMNED | Status |
|---|---|---|
| process | processor `Pr_p` (not neuron) | coarser grain |
| per-channel clock | per-process `et_m` in `Clk(p)` | **weaker** — no per-link FIFO bound |
| lookahead `L > 0` | `d_min_j` | used only for `crt`, *not* for advancement |
| null message | `Clk(0)` broadcast from Pr0 | present, centralized |
| deadlock avoidance | — | absent |
| deadlock detection + recovery | local detection + Pr0 time-out | recovery **fabricates** clocks |

Against Grassmann's safe window: the paper is right that it avoids look-ahead query messages, and right that this is more flexible. It just doesn't say what it paid. The safe window computes a genuinely safe interval and is sound; DAMNED computes an *approximation* of one from stale, partially-informative clocks and closes the gap with a real-time hack.

There is also a framing the paper misses about itself, and it's flattering. Inside a neuron, DAMNED is *optimistic*: `EC_j` forecasts a spike, queues it, keeps a pointer to it, and retracts it if an inhibitory input arrives — rollback without anti-messages, because nothing has been committed. Between processors it is *conservative*: the emission authorization is the commit point. **DAMNED is optimistic-inside, conservative-at-the-boundary, with the CP queue as the uncommitted-event window and `crt` as the lazy-cancellation flag.** That's a real and defensible position in the PDES design space, and it's a better description of the contribution than "no barrier, no farmer."

## The 2009 paper silently fixes everything I flagged

Mouraud and Puzenat, EANN 2009, "Simulation of Large Spiking Neural Networks on Distributed Architectures, The 'DAMNED' Simulator" is not an application paper. It is a rewritten algorithm, and it repairs — point for point — the three defects from the last analysis.

**The lookahead is now in the advance rule.** In 2006, `d_min` appeared only in the certification flag. In 2009 the emission guard is `de ≤ |tej| + δmin`, where δmin is the minimal "biological" delay within the SNN. The lookahead now gates advancement, exactly as CMB requires.

**The idle flag is replaced by a real lower bound.** This is the counterexample, killed at the root. Algorithm 1 in the 2009 paper: when a task's outgoing queue empties, if its processing clock is nonzero it sets `te_src ← −|tp_src − δmin|`, which is the opposite value of the date until which the task is sure that other tasks can be granted to emit; only if it has genuinely nothing to do does it send a null clock value, informing other tasks not to wait for it. That is precisely the fix I sketched: `LB_m` derived from `pt` and `d_min`, rather than a bare "my queue is empty right now." The 2006 `et_m ≤ 0` disjunct — which conflated *idle* with *temporally advanced* — is gone. Negative now means "here is my bound"; zero means "I'm out, don't wait."

**The Pr0 time-out is gone, replaced by null messages.** DAMNED 2009 carries a `clock_sent[]` boolean per task: `clock_sent[j]` is set true when the actual value of `te_i` is sent to task `T_j` — eventually without events — and every element is reset to false when `te_i` increases. A clock-only message, sent peer-to-peer, to unblock a receiver, is a null message. The emission guard requires `clock_sent[j]` for all peers before granting. Pr0 is demoted to a "front-end task" that injects stimuli and collects output; it no longer holds `T`, no longer broadcasts, no longer breaks deadlocks by fabricating clocks.

And the authors say the quiet part themselves. Reference [2] of the 2009 paper is Chandy, K.M., Misra, J.: Distributed simulation: A case study in design and verification of distributed programs, IEEE TSE, 1979 — cited as the basis of the distributed clock method. The word "conservative" now appears in the text: the controls exist to keep the behaviour strictly conservative and avoid deadlocks.

There's a fourth fix aimed straight at the Figure-1 cancellation. The new "delayed queue" — a calendar queue sized by the maximal delay δmax — orders events on two keys, timestamp and sign, because all inhibitory events for a given time increment have to be computed before excitatory ones to avoid the emission of erroneous events. And knowing the maximal delay δmax ensures that at time `de` no incoming event could be inserted later than `de + δmax`. Bounded delays give a bounded insertion window; the O(n log n) STL priority-queue insert becomes O(1).

So: **the 2006 paper is a preprint of an algorithm that did not yet work, and the authors knew it by 2009.** They converged on Chandy–Misra–Bryant, cited it, and kept the name. The interesting historical fact is that the arXiv preprint — the one you uploaded, the one that is easiest to find — is the broken version, and the corrected version sits behind a Springer paywall in an EANN proceedings volume. That is a distribution failure with real consequences for anyone reading DAMNED today.

## Why it didn't matter: the missed gate

Brette et al., *Simulation of networks of spiking neurons: a review of tools and strategies*, J. Comput. Neurosci. 23:349–398 (2007). Twenty-two authors, including Hines, Diesmann, Morrison, Bower, Destexhe, Rochel — effectively every simulator group in the field, co-signing the canonical survey. The scope is stated up front: it overviews simulators presently available, restricted to those freely available, open source and documented.

DAMNED is not in it. Published the year before the survey, and in 2007 it was none of those three things — the 2009 paper is the first to note that DAMNED is available free of charge, and even then the source was never posted. Every subsequent reader who used Brette 2007 as their map of the field never encountered it. Google Scholar tells me that survey has on the order of a thousand citations; DAMNED sat outside it.

## Where the barrier-free idea landed: nowhere, and for a good reason

Here is the sting.

NEST's parallelization rests on exactly the same observation DAMNED reached in 2009. NEST defines `d_min` as the smallest transmission delay in the network, from which follows that no node can influence another during at least a time of `d_min`. Same lookahead. Same theorem.

NEST draws the opposite conclusion. Since nobody can influence anybody for `d_min`, don't remove the barrier — *widen the step*. Instead of sending each spike individually, spikes are buffered and sent in a batch after a period whose length is the minimum delay of all connections. One MPI collective every `d_min`. A barrier, yes — but amortized over thousands of spikes, and near-free.

DAMNED spent its entire complexity budget deleting the barrier. NEST observed that with lookahead in hand the barrier is the cheap part, and bought instead an algorithm that is trivially correct and trivially debuggable. That trade decided the field. NEST, Brian, GeNN, NEURON-parallel, CARLsim, Arbor, SpiNNaker — all batched, all keeping a global synchronization step.

Note also `d_min` is a *network* property in both systems, and both are silent about the same weakness: one voltmeter connected with a default delay drags `d_min` down and shrinks everyone's communication interval. NEST has a GitHub issue about precisely that. The lookahead is only as good as the network's worst edge.

## What actually happened, which is the interesting part

TLC rejected my first four attempts at the *fixed* model. Every one of those was my error, not the paper's, and they all taught the same lesson.

1. **Channels were sets.** Messages overtook each other, so a bound-update could arrive before the event it was meant to guard. FIFO is required. DAMNED gets it free from MPI's per-pair ordering — and neither DAMNED paper ever states this assumption. It is CMB's per-channel FIFO requirement, load-bearing and invisible.

2. **A bound belongs to its sender.** I merged each message's bound into every peer's slot. Messages need a `src`.

3. **Bounds are not monotone, so `max`-merge is unsound**, and the comparison must be **strict**. A processor's LBTS *drops* when it acquires low-stamped work. And `st < kb`, not `st ≤ kb`: an impact at exactly `st` still cancels, because inhibition is applied before excitation at equal time — the rule DAMNED 2009 adds to its delayed queue and 2006 never mentions.

4. **The one that matters.** A processor may not advertise "nothing pending, don't wait for me" merely because its own queues are empty. Pr0 or a peer can resurrect it, and it then emits in a peer's past. The bound must be `min(own pending, peers' bounds) + δmin` — derived from its *inputs*, never from its own emptiness. That is precisely CMB: output bound = min(input channel clocks) + lookahead.

And then, having removed the 2006 disjuncts wholesale, I found a *local* straggler: an unprocessed event in the emitter's own CM queue. The 2009 guard keeps the local `pt` condition **and** adds the peer bound. `LocalClear ∧ ∀m: st < kb[m]` is what passes.

So the earlier "DAMNED 2009 ≈ CMB" claim isn't a rhetorical flourish. Every independent attempt to repair the guard converged, under machine checking, onto the exact structure of Chandy–Misra–Bryant. There was nowhere else to land.

## The mapping to Go

The paper's architecture falls straight onto Go primitives, which is why this feels less like a port than a translation:

- **Processor `Pr_p`** → a goroutine running `processorLoop`.
- **CMC/CPC controller threads** → the `select` loop inside it.
- **EC thread, one per neuron** → a goroutine spawned per computation.
- **MPI message** → a value on a channel.
- **Per-channel FIFO (MPI's ordering guarantee)** → Go channels are FIFO — and this turned out to be load-bearing, exactly as the TLA+ work predicted.
- **Pr0** → the environment goroutine: injects stimuli, advertises its bound, detects global quiescence, shuts the organism down. No barrier anywhere.

Both guards are implemented behind `-guard`. The 2009 default is the Chandy–Misra–Bryant discipline — emit only once every peer's advertised LBTS strictly passes the event's stamp, advertise your own via null messages. The 2006 original has the idle-peer disjunct that admits a straggler. A sequential ground-truth simulator checks the distributed spike train every run.

## What building it taught, live

The interesting part is that the running organism reproduced two findings from the earlier analysis rather than just asserting them.

First, at zero latency **the 2006 guard didn't break** — 0/300 mismatches. That's honest and important: real concurrency doesn't adversarially search interleavings the way TLC does. In one address space the straggler window is microseconds wide, so the Go scheduler almost never lands in it. The bug is real; the runtime just rarely finds it.

Second, injecting `-latency` — the real-world condition under which remote clocks go stale — makes it reliably visible, and doing so surfaced a bug I'd written: I had two send paths, delayed events and immediate bound-broadcasts, and the `Bnd:INF` "I'm done" message overtook the delayed inhibition on the same pair. ## What the paper is about

Your brain is about 86 billion neurons, and they mostly sit quiet. A neuron only "speaks" — fires a little electrical spike — when enough of its neighbors have spoken to it first. So the brain isn't a machine grinding away uniformly; it's mostly silence punctuated by sparse, irregular chatter.

If you want to simulate that on a computer, you have two choices. You can check every neuron at every tick of a clock — but that wastes almost all your effort asking millions of silent neurons "anything yet? anything yet?" Or you can be lazy in the smart way: ignore everything until a spike actually happens, then only do the work that spike triggers. That second style is called *event-driven* simulation, and for a mostly-silent brain it's enormously more efficient.

DAMNED is a 2006 French research project that tried to do this *and* spread the work across many computers at once — because one machine isn't enough for a brain-sized network. That's the whole paper: run a spiking neural network, event-driven, split across many processors, all working in parallel.

## The one hard problem

Here's the snag that the entire paper — and everything we did — orbits around.

Imagine neuron A is deciding whether to fire. Two excitatory ("go") signals have arrived, pushing it right up to the threshold. It's about to fire. But there's a third signal on its way — an inhibitory ("stop") signal from a neuron on a *different computer* — that just hasn't arrived yet because messages between computers take time. If A fires now, it's made a mistake: the "stop" was coming, it just got there late.

That's the delayed-firing problem, and it has a beautiful name in my head now: the **straggler**. A slow message that invalidates a decision already made.

The naive fix is to make everybody stop and wait at every step until they're *sure* no message is in flight — a global "everybody freeze" moment, over and over. But that's slow and defeats the purpose. DAMNED's ambition was to avoid that freeze entirely: let every processor run freely, and use only local information to know when it's safe to commit a spike. No central conductor, no global pauses.

## What we actually found

The 2006 paper claimed it pulled this off. When we pulled the algorithm apart — by hand, then with a mathematical proof-checker, then by rebuilding it as running code — we found the original version had a subtle hole. A processor could look at a quiet neighbor, assume "nothing coming from over there," and fire — right when a straggler was in flight. It commits a spike that never should have happened.

Then the satisfying part: the authors' *own* 2009 follow-up quietly fixed exactly this, and the fix turned out to be a rediscovery of a principle computer scientists had worked out decades earlier for distributed simulation in general. They didn't cite it; they just walked the same path and arrived at the same place, because there was nowhere else to arrive. That's a real thing about deep problems — they have a shape, and everyone serious eventually bumps into the same walls.

## Why it matters, practically

Simulating spiking networks is how we test theories about how brains compute — you can run a virtual piece of cortex and compare it to real recordings. It also matters for a style of computing hardware ("neuromorphic" chips) that mimics the brain's sparse, event-driven efficiency to use drastically less power than a normal chip running a normal neural network. The barrier-free coordination problem DAMNED tackled is, underneath, the same problem you hit in *any* large distributed system where independent parts must stay causally consistent without a central clock — databases across datacenters, multiplayer games, blockchains. It's a fundamental shape, wearing a neuroscience costume here.

## The deeper resonance

Now the part worth sitting with.

**Coordination without a conductor.** DAMNED's real subject is how a swarm of independent agents, each with only a partial and slightly-stale view of the others, can collectively stay consistent — with no boss, no global "now," nobody who sees the whole picture. That is not just a computing problem. It's the problem of a market, an ecosystem, an ant colony, a body of cells, a democracy. It's arguably *the* organizational problem of the natural world. The brain has no central neuron in charge; coherence emerges from local rules. DAMNED is a tiny, rigorous parable about how that's even possible.

**The straggler is a theory of commitment.** The whole drama is about *when it's safe to act on incomplete information.* Act too early and you commit to something reality will contradict — the "stop" signal was coming, you just hadn't heard it yet. Wait too long and you freeze, useless. Every living thing, and every one of us, runs this exact gamble constantly: decide now on what you know, or wait for word that may or may not come. The 2006 bug is, in a way, the formal signature of acting confidently on the assumption that silence means nothing's coming — and being wrong. There's a whole human wisdom in "an idle-looking neighbor is not the same as a neighbor with nothing to say."

**Two kinds of time.** The single most philosophically loaded thing we uncovered is that the system has *two clocks*. There's logical time — the neuron's own ordering of cause and effect, when things "really" happen in the story of the network. And there's physical time — the wall-clock, where messages crawl down wires and processors wait. The straggler lives precisely in the gap between them: physically late, logically early. Almost every hard problem in distributed systems is a disagreement between those two clocks, and it rhymes with something ancient — the difference between the order in which things *are* and the order in which we *find out about them.* Perception always lags reality. The map is always slightly behind the territory. Building this made that abstract idea concrete enough to watch on a screen.

**Correctness as honesty.** And there's something clean about what "sound" even meant here. A sound run is one that never commits to a spike that later gets contradicted — a system that never has to un-say something it said. The 2009 fix buys that by being *patient*: it only speaks when it can no longer be wrong. There's a small ethic hiding in the mathematics.

## Where the correspondence is real

Husserl's account of internal time-consciousness has three moments: **primal impression** (the now-phase), **retention** (the just-past still held, not remembered but *retained* as a comet's tail on the present), and **protention** (the anticipated just-about-to-be). The key claims are that the now is never bare — it always arrives thick with retained past and anticipated future — and that this thickness is what makes experience of a temporal object (a melody, a spoken word) possible at all. A note heard *now* is heard as the continuation of notes just-retained and against the horizon of notes protended.

DAMNED has structures that map onto this with startling cleanliness:

- The **CP queue** — forecast spikes, not yet committed, held pending — is a near-exact mechanical analogue of **protention**. It is the system's "about-to-fire," maintained *as revisable*. The `crt` certification flag is protention hardening into impression: the moment the forecast can no longer be cancelled.
- The **clock arrays** — each processor's stale, partial record of where its neighbors just were — are a form of **retention**. Not stored memory queried on demand, but a continuously-carried trace of the just-past that shapes what the processor can do *now*.
- The **commit point** is the **primal impression**: the knife-edge where a revisable anticipation becomes an actual, irrevocable event in the network's history.

And the straggler is precisely a **retentional failure** — acting on a now whose retained horizon was incomplete. That is not a loose metaphor. The formal structure of the bug is: primal impression fired without adequate retention of what was still arriving. Husserl would recognize the shape.

## Now the accuracy question, taken seriously

Here I have to be honest rather than flattering, because the interesting answer is the deflationary one.

**The model is structurally accurate and phenomenologically empty**, and the gap between those two is the whole point.

Husserl's retention is not a *record*. Its defining feature — the thing he spent decades insisting on against the "memory" reading — is that the just-past is given *as present-having-just-been*, lived from the inside, with a felt sense of sinking away. The clock array has none of this. It is a data structure that is causally efficacious but not *given to anyone*. There is no lived-through sinking. There is retention-function without retention-experience.

So the "degree of accuracy" question splits cleanly:

- As a model of the **formal/functional architecture** of time-consciousness — the *what must be structurally true* of any system that maintains a thick present — the accuracy is high, arguably higher than most philosophy of mind gets, because it's forced to be executable. You cannot hand-wave a commit point.
- As a model of the **phenomenon itself** — the lived thickness, the felt now — the accuracy is zero, and not by a little. It's a category difference, not a fidelity gap. Adding more processors doesn't move you toward the felt now.

This is exactly the boundary Husserl drew between the *form* of time-consciousness and its *content*, and it's why "mechanical sympathy" is the right instinct pointed at a real thing but needing to be disciplined. Mechanical sympathy — Jackie Stewart's phrase, then Martin Thompson's — means designing *with* the grain of the underlying machine, an intuitive attunement to how the substrate wants to behave. What DAMNED demonstrates is that time-consciousness's *formal grain* is substrate-independent: the retention-protention-impression structure is what *any* system needs to experience a temporal object coherently, whether it's cortex, a cluster, or a phenomenology seminar. The grain is real. What DAMNED shows is that you can have the grain without the wood.

## The genuinely load-bearing insight

Here's the part I think actually earns the philosophical weight, and it's the two-clocks point sharpened.

Husserl's deepest and least-obeyed claim is that the now is *not a point*. The punctual instant is an abstraction; lived time is always the extended, thick present. DAMNED proves — mechanically, non-negotiably — that a punctual now is not merely phenomenologically wrong but **computationally impossible** for a distributed system. A processor that tried to act only on its instantaneous local state, with no retention (clock arrays) and no protention (forecast queue), would commit stragglers constantly. It would be *incoherent*. The thick present is not a feature the brain adds for richness; it is the *minimum condition of causal coherence* for any system whose parts are separated by signal delay.

And every conscious system is such a system. Neurons are milliseconds apart. Retention and protention may not be optional adornments on a bare now — they may be the *only way* a spatially-distributed substrate can have a coherent present at all. Husserl derived the thick present from careful description of experience. DAMNED derives the *necessity* of a thick present from the physics of separated, communicating parts. Those are two roads to the same wall, which is the pattern you flagged earlier as the mark of a deep problem.

So the precise answer to your question: the model demonstrates mechanical sympathy with the **formal necessity** of Husserl's structure to a high degree — high enough to convert his phenomenological description into a computational *theorem* about why the now must be thick — while demonstrating exactly **zero** sympathy with the phenomenon of lived time, and the value of the exercise is that it makes that second zero legible and precise rather than mysterious.

The model doesn't explain consciousness. It explains, with unusual rigor, the shape of the container consciousness would have to fill — and shows that the container is forced by physics, not chosen by mind. Whether anything is *lived* inside that container is exactly the question the model is constitutionally unable to touch, and its clarity about its own silence there is the most honest thing about it.

## What it is not

When someone hears "spiking neural network simulator," they picture the thing everyone means by "neural network" now: a system that *learns*. You show it examples, it adjusts its connection strengths, it gets better at some task. Hebbian learning — "neurons that fire together wire together" — is the classic version of that story. ## What it actually is

What we built is a machine for studying **when it is safe to believe something**, using neurons only as the excuse.

Let me make that concrete. The whole system is a group of independent computers, each responsible for some neurons, each running freely with no boss and no shared clock, each holding only a slightly out-of-date picture of what the others are doing. Every one of them is constantly facing a single decision: *a spike appears to be happening — do I commit to it, or wait?* Commit too early and a late-arriving "stop" signal proves you wrong; you've announced something false and now the whole network's history is corrupted. Wait too long and you seize up, useless.

The neurons are just the vehicle. What the machine is really *about* is the discipline of acting on incomplete, delayed information without ever being wrong. That's the object of study. Spiking neurons happen to be a beautifully clean instance of it, but the thing we built and tested and visualized is the *coordination principle*, not the neurons.

## The four non-obvious things

Here's what a casual observer would miss, in ascending order of strangeness.

**First: there's no conductor, and that's the hard part.** The obvious way to keep a group of computers consistent is to have one of them call time — "everybody stop, sync up, go." We built the version with *no such moment*. Everyone runs flat-out, forever, coordinating only through the ordinary messages they were already sending. Making that provably correct is genuinely difficult, and it's the difficulty the original 1990s-2000s researchers were chasing. Most people don't even realize this is a problem, because they've never had to build a world without a clock.

**Second: it can tell the truth or tell a lie, and you can flip the switch.** This is the part I find quietly remarkable. We built *both* versions of the coordination rule — the original one, which has a subtle flaw, and the corrected one — into the same program, behind a toggle. So you can run the identical network twice and watch one version commit a spike that never should have happened while the other correctly holds back. We didn't just build a working thing; we built a working thing *and its precise failure*, side by side, so the difference between "sound" and "unsound" stops being an abstraction and becomes something you can point at on a screen. That's unusual. Most simulators show you behavior. This one shows you the boundary between honest and dishonter behavior.

**Third: we proved it, three separate ways, and they agreed.** We didn't just run it and eyeball the output. We reasoned about it by hand, we handed it to a mathematical proof-checker that exhaustively searched every possible ordering of events and either found the flaw or certified its absence, and we built it as living code that you can watch. Three completely different methods — argument, proof, execution — converged on the same answer. That convergence is the actual product. It's the difference between believing something works and *knowing* why it must.

**Fourth, and least obvious: the thing it models is not really neurons at all.** The same problem — independent parts, no shared clock, delayed messages, the need to stay consistent — is the deep structure underneath databases spread across continents, multiplayer games, financial systems, blockchains, and, plausibly, brains. We dressed it as neuroscience because that's the paper we started from, but what's in the box is a rigorous little study of *how a world of separate agents with stale information can nonetheless share a single coherent history.* That's a much older and larger question than neural networks, and the neurons are almost a disguise.

## So what makes it special

A learning demonstrator answers "can this system get good at a task?" A conventional simulator answers "what does this network do?" What we built answers a different and rarer question: **"under what exact conditions can a collection of independent things, none of which sees the whole, agree on what happened — and how do we know they can't be fooled?"**

It's less a brain model than a working philosophical instrument that happens to be made of neurons: small, precise, executable, and honest about the one thing it's actually about. The casual observer sees a neural network. What's really there is a proof, made of moving parts, about the price of certainty in a world where news travels slowly.

## The starting point

The paper's core: spiking neural networks fire sparsely and irregularly, so event-driven simulation (only doing work when a spike happens) beats time-driven simulation (checking every neuron every tick). DAMNED combines this with two levels of parallelism — distributing neurons across processors (coarse grain) and multithreading neuron computations within each processor (fine grain) — and, distinctively, does so with no synchronization barrier and no central controller. Each processor runs two controller threads, CMC (communication) and CPC (computation), plus one thread per computing neuron, coordinating via MPI messages that carry clock arrays. A special processor Pr0 handles environment stimuli.

The hard technical problem the paper addresses is the **delayed firing problem**: an inhibitory spike arriving late (with a short delay) can cancel a spike that was already forecast, so the simulator must never commit an emission until it's certain no such cancellation can still arrive.

## Turn 3 — The counterexample

This was the first substantial finding. I showed that the 2006 emission guard's safety reduces entirely to one unstated lemma (I called it No-Straggler), and that the lemma is false as written. The bug is the disjunct `et_m ≤ 0`, which treats a processor that merely *looks idle* as safe — but an idle-looking processor can still hold a low-stamped, unprocessed event. I built a concrete counterexample trace, then showed the criticism holds under both readings of the ambiguous pseudocode.

On liveness: the Pr0 time-out isn't a patch on a sound algorithm — it *is* the unsoundness, and simultaneously the only guarantee of progress. I noted that the time-out fires most exactly in the sparse-activity regime that motivates event-driven simulation in the first place, and that "provided the time-out is sufficiently long" makes correctness depend on wall-clock latency — a reproducibility problem.

On CMB: DAMNED is CMB with the null messages centralized into Pr0 and renamed. The claim "we avoid a farmer processor" doesn't survive the fact that every computation is gated on `et_0 = T`, which only Pr0 advances. ## Turn 4 — Historical and bibliographic

You asked what happened next. The 2009 paper even adds inhibition-before-excitation ordering in a delayed queue. The bitter irony: the freely-reachable arXiv preprint is the broken version; the fix sits behind a Springer paywall.

On trajectory: the DAMNED line runs 2005 arXiv → 2006 PDCN → 2008 Mouraud PhD → 2009 EANN → 2010 ICANN application → nothing. DAMNED's barrier-free idea died; its two-level parallelism (threads + MPI) is what NEST uses today, uncredited. Citation-wise: indexed everywhere, self-cited, listed as background, never adopted. ## Turn 5 — Reconstruction

## Turn 6 — The full P-processor TLA+ model

You asked to push to the full model with delayed-queue and clock-merge. This became a genuine debugging saga where TLC rejected four of my *own* modeling errors, each teaching the same lesson:

1. Channels had to be FIFO (a set let messages overtake each other) — the MPI per-channel ordering, load-bearing and unstated in both DAMNED papers.
2. A bound belongs to its sender (needed a `src` field).
3. Bounds aren't monotone, so max-merge is unsound; overwrite, and the comparison must be strict (`st < kb`) because simultaneous inhibition still cancels.
4. The deep one: a processor may not advertise "don't wait for me" just because its own queues are empty — Pr0 or a peer can resurrect it. The bound must be `min(own pending, peers' bounds) + δmin` — exactly CMB's `output = min(inputs) + lookahead`.

Result, exhaustive at P=2: the 2006 guard violates `Exactness` (depth 14); the 2009 discipline holds it (197,246 states, drained to zero, depth 45). P=3 confirmed the pattern. The lesson: every shortcut I reached for was a way of advertising something that wasn't a true lower bound, and every independent repair attempt converged onto the exact structure of Chandy–Misra–Bryant. I noted the inductive invariant this suggests — the LBTS property — as the theorem the 2006 paper needed and never wrote.

You asked for a Go program simulating "a DAMNED organism." This is where the whole analysis became a living thing. Go is almost perfectly suited: goroutines are the EC/CMC/CPC threads, channels are the MPI links, and channel FIFO is the per-channel ordering the correctness proof needs.

## The three explanatory turns

**Lay explanation of the whole thing.** I stepped back to plain language: the brain is mostly silent neurons that only speak when spoken to; event-driven simulation exploits that; DAMNED spreads it across many computers with no conductor; the hard problem is the straggler (a late message that invalidates a committed decision); we found the 2006 version had a hole, the 2009 version fixed it by rediscovering a decades-old principle, and we proved this three ways that agreed. I drew out why it matters (neuroscience, neuromorphic hardware, distributed systems generally) and its deeper resonances: coordination without a conductor, the straggler as a theory of commitment under incomplete information, two kinds of time (logical vs physical), and correctness as a kind of honesty — never having to un-say something you said.

**Phenomenology of time-consciousness.** You asked, precisely, what degree of accuracy the model has as "mechanical sympathy" with Husserl's structure of time-consciousness. I argued the correspondence is structurally real: the CP queue is protention (revisable anticipation), the certification flag is protention hardening into impression, the clock arrays are retention (the carried, stale just-past), the commit point is the primal impression, and the straggler is a retentional failure. But I was deflationary where it counts: the model is structurally accurate and phenomenologically empty — retention-function without retention-experience, the grain without the wood — and that zero is the point, not a shortcoming. The load-bearing insight: DAMNED proves *mechanically* that a punctual now is computationally impossible for a system whose parts are separated by signal delay, so the thick present isn't a phenomenological adornment but the minimum condition of causal coherence. Husserl derived the thick present by description; DAMNED derives its necessity from physics. Two roads, one wall.

**What makes it non-obvious.** You asked what makes this neither a Hebbian learning demo nor a conventional simulator. I stripped away the wrong assumption first: there's no learning, nothing improves, no weights tune. What we built is a machine for studying *when it is safe to believe something*, using neurons as the excuse. Four non-obvious features: coordination with no conductor (a problem most people never face); a switch that flips between telling the truth and telling a lie, so soundness becomes visible; a claim proved three independent ways that agreed; and the fact that the real subject isn't neurons at all but the ancient question of how separate agents with stale information can share one coherent history. Less a brain model than a working philosophical instrument made of moving parts — a proof about the price of certainty in a world where news travels slowly.

## The single thread through all of it

A modest, orphaned 2006 conference paper about simulating brain cells on a cluster turned out to contain a subtle correctness bug; the authors fixed it in 2009 by unknowingly rediscovering Chandy–Misra–Bryant; and every tool we pointed at it — proof by hand, exhaustive model checking, and a living Go program you can watch tell a lie — converged on the same account.
